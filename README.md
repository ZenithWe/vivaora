# VIVAORA — Website

Starter frontend da agência VIVAORA, criado com Next.js, React, TypeScript e Tailwind CSS.

## Executar localmente
```bash
npm install
npm run dev
```

Acesse http://localhost:3000.

Rotas incluídas: `/`, `/viagens` e `/contato`.

Os pacotes, valores, imagens e contatos são demonstrativos. Não há consulta real de disponibilidade, reserva, cobrança ou processamento de dados pessoais no backend.
